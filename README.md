Electricity Usage Predictor

Project Overview

Electricity Usage Predictor is a Python-based project that uses Simple Linear Regression to predict future electricity consumption based on previous monthly usage data.

Features

- Reads electricity usage data from a CSV file.
- Uses NumPy for Linear Regression.
- Predicts electricity consumption for a future month.
- Estimates the electricity bill at ₹6 per unit.
- Calculates the R² score.
- Displays a graph showing actual usage, regression line, and future prediction.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

Project Files

- "predictor.py" – Main Python program.
- "usage.csv" – Electricity usage dataset.

Installation

Install the required libraries:

python -m pip install pandas numpy matplotlib

How to Run

python predictor.py

Enter a future month number when prompted.

Dataset Format

Month| Units
1| 100
2| 120
3| 150
4| 170

Bill Calculation

Estimated Bill = Predicted Units × ₹6
